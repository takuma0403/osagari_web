## ADMIN 管理者機能

管理者は、出品者の承認、トラブル対応、お金まわりの設定を担当します。

- 学生証の審査（承認・差し戻し）と、画像の閲覧記録の確認
- 出品の停止と、ユーザーのアカウント停止
- 取引状況の確認と、キャンセル・返金（モック）の手動対応
- 手数料率の設定
- 退学申請の受け付けと、アカウントの削除
- 有効期限の手動変更（延長の仕組みができるまでの暫定対応）

- 教職員（[AUTH-5](01-account-auth.md)）は、ユーザーの検索で学籍番号の代わりにメールアドレスで探せるようにし、一覧の学籍番号・学部の欄にはメールアドレスと「教職員」を出します。身分証の審査は学生証と同じ審査待ちの一覧に、種別を付けて並べます（[ADR 0051](../decisions/0051-staff-accounts.md)）。
- 退学申請の受け付けには、教職員の退職などによる削除の申請も含みます。

各操作の対象と後処理（停止と解除、退学による削除、出品の停止、取引のキャンセル、手数料率の変更）は [ADR 0034](../decisions/0034-admin-users-deals-settings.md) で決めています。
