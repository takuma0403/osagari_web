# ユーザー・認証・アカウント期限（要件）

> 関連: [技術：認証](../tech/auth.md) / [データモデル](09-data-model.md) / 画面: Login, SignUp, Code, Password, Recheck（[デザイン](../design/README.md)）

## AUTH ユーザー・認証・アカウント期限

アカウントは `@edu.cc.saga-u.ac.jp` のメールアドレスでのみ作成できます。有効期限は学籍番号から自動で設定します。

### AUTH-1 登録・ログイン

- **新規登録**：メールアドレスを入力すると、ドメインが `@edu.cc.saga-u.ac.jp` かどうかを確認し、6桁の認証コードをメールで送ります。コードの認証に成功したらパスワードを設定し、アカウントを作成します。
- **規約への同意**：新規登録の最初の画面に「登録すると[利用規約](../legal/terms.md)と[プライバシーポリシー](../legal/privacy.md)に同意したものとみなします。」と両文書へのリンクを出し、登録をもって同意とします。チェックボックスは置かず、同意したことは記録しません。両文書はログイン画面と、ログイン後はマイページからいつでも開けます（[ADR 0040](../decisions/0040-terms-consent-and-mypage-links.md)）。
- **通常のログイン**：メールアドレスとパスワードでログインします。
- **定期的な再確認**：最後にコードで確認してから30日たった場合や、初めて使う端末の場合は、パスワードに加えてメールの認証コードの入力を求めます。卒業などで大学のメールが使えなくなると、この再確認ができずログインできなくなります。
- **パスワードの再設定**：メールの認証コードで本人確認をしてから、新しいパスワードを設定します。
- メールアドレスの@より前を学籍番号として保存します。
- 詳しい仕組みと流れの図は、技術構成ドキュメントの「認証」の章にあります。

> 技術構成ドキュメントの「認証」の章 → [tech/auth.md](../tech/auth.md)

### AUTH-2 学籍番号から推定する情報

- 学籍番号から入学年度と学部を推定し、ユーザー情報に登録します。
- 推定した学部は、検索の絞り込みや出品者の表示に使えます。

### AUTH-3 有効期限と失効

- 有効期限は「入学年度 + 修業年限（医学部医学科は6年、それ以外は4年）」の3月31日を初期値にします。
- 退学の申請があった場合は、その時点でアカウントを削除します。申請は本人がアプリから行い、管理者が受け付けて削除します。削除するときは、下の失効と同じ後処理を行います（学生証の削除予定日は削除日 + 3年。[ADR 0034](../decisions/0034-admin-users-deals-settings.md)）。
- 申請がなければ、通常の期限で失効させます。失効日は有効期限の翌日で、日次ジョブが失効させます（[JOBS-1](../tech/jobs-payment-mock.md)）。
- 失効したときは、本人の商品を取り下げ、本人が関わる承認待ちの購入希望を期限切れにし、取引中の取引をキャンセルして購入者に返金します。取引完了済みの取引と未出金の売上は変えません（[ADR 0033](../decisions/0033-account-expiry-and-daily-job.md)）。
- 失効・削除のときに未出金の売上は、失効・削除の日から6か月以内に問い合わせの窓口へ申し出れば出金します。6か月を過ぎたら出金を求められません。有効期限が近づいた利用者には出金を促します（[ADR 0037](../decisions/0037-no-auto-complete-unpaid-sales-fee-rate.md)）。
- メールアドレス・学籍番号・取引の記録などアカウントに結びつく情報は、失効・削除から3年で削除するか、個人を特定できない形にします（[プライバシーポリシー 第７条](../legal/privacy.md)、[ADR 0036](../decisions/0036-terms-and-privacy.md)）。
- 延長の仕組み（留年、6年制の学科、大学院進学など）は後で検討します。

### AUTH-4 学籍番号の構成と学部コード

学部生の学籍番号は8桁で、「入学年度（西暦の下2桁）＋学部・学科コード（3桁）＋連番（3桁）」で構成されます（[2019年度 全学教育機構 履修の手引き](https://www.sc.admin.saga-u.ac.jp/tebiki-h31-kyoyo.pdf)）。メールアドレスは「学籍番号@edu.cc.saga-u.ac.jp」です（[LiveCampus利用説明資料](https://www.sc.admin.saga-u.ac.jp/livecampus_setumei.pdf)）。

```
26 238 001
│   │   └ 連番
│   └ 学部・学科コード（例：理工学部 理工学科）
└ 入学年度（2026年度）
```

| コード | 学部・学科 | 修業年限 | 出典・備考 |
| --- | --- | --- | --- |
| 101 | 教育学部 学校教育課程 | 4年 | 2019年度手引き。2026年度の手引きには「共同教員養成課程」とあり、コードが変わっていないか要確認 |
| 121 | 芸術地域デザイン学部 芸術地域デザイン学科 | 4年 | 2019年度手引き |
| 141 | 経済学部 経済学科 | 4年 | 2019年度手引き |
| 142 | 経済学部 経営学科 | 4年 | 2019年度手引き |
| 143 | 経済学部 経済法学科 | 4年 | 2019年度手引き |
| 211 | 医学部 医学科 | 6年 | 2019年度手引き |
| 212 | 医学部 看護学科 | 4年 | 2019年度手引き |
| 238 | 理工学部 理工学科 | 4年 | 2019年度手引き |
| 254 | 農学部 生物資源科学科 | 4年 | 2019年度手引き |
| 271 | コスメティックサイエンス学環 | 4年 | 2026年度新設（[2026年度 学環 履修の手引](https://www.sc.admin.saga-u.ac.jp/tebiki-r8-cosme.pdf)） |

- **有効期限の初期値**：「(2000 + 上2桁) + 修業年限」年の3月31日とします。例えば 26238001 なら2030年3月31日、26211001（医学科）なら2032年3月31日です。
- **大学院生**：同じ8桁の形式ですが、研究科のコード表は公開資料で見つかっていません。学内の公開資料では、学校教育学研究科が321、先進健康科学研究科が626、理工学研究科が726〜729で始まる番号が使われています（[2024年度 交通安全講習会 許可者一覧](https://www.sc.admin.saga-u.ac.jp/wp-content/uploads/2024/03/R6_koutuanzen-kyoka_tsuika.pdf)）。修業年限（修士2年・博士3年など）とあわせて大学に確認します。
- **改組前のコード**：2018年度以前の入学者には、旧学部のコード（文化教育学部 111〜114、理工学部 231〜237、農学部 251〜253）が残っている可能性があります。
- **表にないコードの扱い**：学部を「不明」として登録し、有効期限は入学年度＋4年とします。管理者が後から修正できるようにします。

### AUTH-5 教職員の利用（検討保留）

教職員も利用できるようにしたいと考えています。詳細の検討は保留中で、現時点で決まっているのは次の前提だけです。

- 教職員用の画面とAPIは、学生用とは分けて作ります。
- 教職員のメールアドレスは学籍番号の形式（数字8桁）ではないため、数字以外も受け付ける必要があります。
