# 一覧・検索・共有（要件）

> 関連: [技術：フロントエンド（ルーティング・共有リンク）](../tech/frontend.md) / 画面: Main, Search, Detail, DetailShare（[デザイン](../design/README.md)）

## BROWSE 一覧・検索・共有

紹介機能は、公開中の商品の一覧ページとして実装します。それに加えて、検索とリンクによる共有に対応します。

- **一覧ページ**：公開中の商品を新着順に並べ、カテゴリ別に切り替えられるようにします。
- **検索**：キーワード、カテゴリ、授業名、価格帯、キャンパス、状態で絞り込みます。
- **共有リンク**：商品ページごとに固定のURLを持たせ、コピーやシェアのボタンを置きます。コピーするときは、商品名・価格・状態とURLをまとめた文章にします。リンクのプレビューが表示されない環境でも、内容が伝わるようにするためです。
- 共有リンクをログインしていない人が開いたときの扱い（ログイン画面へ誘導するか、概要だけ見せるか）は未定です。

**一覧と商品ページに出す商品**（[ADR 0018](../decisions/0018-browse-visible-items.md)）

| 商品のステータス | 一覧・検索 | 商品ページ（共有リンク） |
| --- | --- | --- |
| 公開中・購入希望あり | 出す | 出す |
| 取引中・取引完了 | 出さない | 売り切れとして出す（購入希望は出せない） |
| 下書き・取り下げ・停止 | 出さない | 見つからない（出品者本人も同じ） |

- 出品者のアカウントが使えない（停止・失効・削除、または有効期限を過ぎた）商品は、一覧・検索にも商品ページにも出しません。
- 一覧と検索結果は、最後に公開した日時の新しい順に並べます。キーワードはタイトル・説明文・授業名・担当教員・ISBN から探し、空白で区切った語をすべて含む商品を出します。
- 商品ページに出す出品者の情報は、学部・学科と入学年度だけです。学籍番号は取引成立後まで出しません（[DEAL-1](05-deal-flow.md)）。
