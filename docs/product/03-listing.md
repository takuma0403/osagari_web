## ITEM 出品・商品管理

出品には、すべてのカテゴリで共通の項目を入力します。カテゴリによっては追加の項目も入力できます。

| 区分 | 項目 |
| --- | --- |
| 共通 | 写真（複数枚）、タイトル、カテゴリ、状態、価格（円）、説明文、受け渡し希望キャンパス（本庄・鍋島） |
| 教科書・参考書 | 授業名、担当教員、ISBN、書き込みの有無 |
| 家具・家電 | サイズ、動作確認の有無 |
| ゲーム・その他 | 共通項目のみ |

- 商品のステータスは「下書き → 公開中 → 購入希望あり → 取引中 → 取引完了」と進みます。出品者はいつでも「取り下げ」にできます。
- 出品者は、自分の出品一覧から編集、取り下げ、再出品ができます。
- 取引中の商品は、価格などを編集できないようにします。
