## ITEM 出品・商品管理

出品には、すべてのカテゴリで共通の項目を入力します。カテゴリによっては追加の項目も入力できます。

| 区分 | 項目 |
| --- | --- |
| 共通 | 写真（複数枚）、タイトル、カテゴリ、状態、価格（円）、説明文、受け渡し希望キャンパス（本庄・鍋島） |
| 教科書・参考書 | 授業名、担当教員、ISBN、書き込みの有無 |
| 家具・家電 | サイズ、動作確認の有無 |
| ゲーム・その他 | 共通項目のみ |

- 出品できるのは、学生証が承認された利用者だけです（[CARD](02-student-card.md)）。
- 商品のステータスは「下書き → 公開中 → 購入希望あり → 取引中 → 取引完了」と進みます。
- 出品者は、自分の出品一覧から編集、取り下げ、再出品ができます。できるステータスは次のとおりです（[ADR 0016](../decisions/0016-item-edit-withdraw-rules.md)）。

  | 操作 | できるステータス |
  | --- | --- |
  | 編集 | 下書き・公開中・取り下げ |
  | 取り下げ | 下書き・公開中・購入希望あり |
  | 公開・再出品 | 下書き・取り下げ |

  - 購入希望あり・取引中・取引完了・停止の商品は、どの項目も編集できません。購入希望はその時点の価格で枠を確保しているためです。
  - 取引中の商品は取り下げられません。やめるときは双方の同意でキャンセルし（[DEAL-4](05-deal-flow.md)）、公開中に戻してから操作します。
- **下書き**：保存するときに必須なのはタイトルだけです。公開するときに、すべての共通項目（写真1枚以上を含む）がそろっているかを確かめます。
- **入力の制限**：

  | 項目 | 制限 |
  | --- | --- |
  | 写真 | 公開時に1〜10枚。1枚5MBまで、JPEG か WebP（[STORAGE](../tech/storage.md)）。並び順が表示順 |
  | タイトル | 1〜100文字 |
  | 説明文 | 2,000文字まで |
  | 状態 | 新品同様・目立った傷なし・やや傷あり |
  | 価格 | 100〜100,000円の整数 |
  | 授業名・担当教員・サイズ | それぞれ100文字まで |
  | ISBN | 10桁か13桁（ハイフンは除いて保存し、チェックディジットを確かめる） |

  カテゴリと合わない追加項目（家具・家電の ISBN など）は受け付けません。

### ITEM-1 禁止出品物

次の物は出品できません。システムでは自動で判定せず、利用規約に書き、見つけたときは管理者が商品を停止します（[ADMIN](07-admin.md)）。利用規約の本文はこの一覧を使って書きます。

- 試験の答案・過去問の配布物、レポートなどの代行物
- 医薬品・医療機器・サプリメント
- 酒類・たばこ
- 危険物・武器
- 偽造品・海賊版・違法コピー（コピーした教科書を含む）
- 個人情報を含む物（名前入りの学生証など）
- チケット・金券・商品券
- 生き物
- 盗品・法令に違反する物
