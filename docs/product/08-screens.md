# 画面一覧（要件）

> 関連: 各画面のデザインとアートボードの対応は [design/README.md](../design/README.md) を参照

## SCREEN 画面一覧

フェーズ1で必要になる画面は、利用者向けが11画面（下表の教職員用の2行を除く）、管理者向けが4画面です。

| 画面 | 主な内容 | 利用者 |
| --- | --- | --- |
| ログイン・登録 | 大学メールアドレスの入力と、メールによる認証 | 全員 |
| 教職員のログイン・登録 | 教職員用のログイン・新規登録・再確認・パスワード再設定（学生用の「ログイン・登録」と同じく1行にまとめる）。@より前の入力とドメインの選択（[AUTH-5](01-account-auth.md)） | 教職員 |
| 商品一覧 | 新着順の一覧、カテゴリの切り替え | 全員 |
| 検索結果 | 条件による絞り込み | 全員 |
| 商品詳細 | 写真、商品情報、購入ボタン、共有ボタン | 全員 |
| 購入希望・決済（モック） | 金額の確認と購入希望の送信（支払い枠の確保） | 購入者 |
| 取引一覧 | 購入と出品それぞれの、進行中・終了した取引の一覧と状態。出品側の購入希望は商品ごとに件数で出す（[ADR 0028](../decisions/0028-transaction-list.md)） | 全員 |
| 取引詳細 | 取引の状態、購入希望の一覧と承認（出品者）、確認モーダル（出品者）、相手の学籍番号、受け渡しQRの表示（出品者）と読み取り（購入者）、完了リンク・コードの発行と入力、キャンセルの申請と同意 | 当事者 |
| マイページ | プロフィール、有効期限、出品と購入の履歴、利用規約・プライバシーポリシーへの導線（[ADR 0040](../decisions/0040-terms-consent-and-mypage-links.md)） | 全員 |
| 学生証登録 | 画像のアップロードと審査状況の確認 | 出品希望者 |
| 身分証登録 | 教職員の身分証画像のアップロードと審査状況の確認（[CARD](02-student-card.md)） | 出品を希望する教職員 |
| 出品・編集 | 商品情報の入力と写真のアップロード | 出品者 |
| 売上管理 | 売上の一覧、手数料、出金状況（モック） | 出品者 |
| 管理：学生証審査 | 審査待ちの一覧と、承認・差し戻し | 管理者 |
| 管理：ユーザー | 検索、停止、有効期限の変更、退学による削除 | 管理者 |
| 管理：出品・取引 | 出品の停止、取引への対応 | 管理者 |
| 管理：設定 | 手数料率の設定 | 管理者 |

- 教職員の画面（教職員のログイン・登録、身分証登録）はキャンバスにデザインがないため、Login・SignUp・Code・Password・Recheck・StudentCard の既存の部品で組みます。学生用のログイン画面から「教職員の方はこちら」で移れるようにします（[ADR 0051](../decisions/0051-staff-accounts.md)）。
- 試験運用中（[OVERVIEW](00-overview.md)、[利用規約 第２条](../legal/terms.md)）は、その端末で初めて開いたとき、どの画面でも（利用規約・プライバシーポリシーを除く）「実際のお金の支払い・受け取りは発生しない／実際の売買に使わない」を伝えるダイアログを一度だけ出します（[ADR 0039](../decisions/0039-trial-notice-dialog.md)。実装は [FE-1](../tech/frontend.md)）。
