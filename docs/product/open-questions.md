## OPEN 保留事項・今後の検討

- [ ] 学部・学科コードの最新版と、大学院の研究科コードを大学に確認する
- [ ] 同じドメインのアドレスを、教職員や留学生も持っているか確認する
- [ ] 有効期限の延長の仕組み（留年、医学部医学科などの6年制、大学院進学、編入）
- [ ] 失効時に、進行中の取引、公開中の商品、未出金の売上をどう扱うか
- [ ] 自動完了を導入するか（導入する場合は7日が妥当か、導入しない場合は止まった取引をどう扱うか）
- [ ] 購入希望の承認期限（48時間）が、決済サービスのオーソリ有効期限と合っているか
- [ ] 手数料率
- [ ] 決済代行サービスの選定と、出金先にPayPayを指定できるか
- [ ] 共有リンクをログインしていない人が開いたときの表示
- [ ] 禁止出品物の規約（試験の答案、医薬品、酒類など）
- [ ] 商品Q&Aを付ける場合の形（公開の書き込み欄にする想定）
- [ ] 利用規約とプライバシーポリシー（学生証の保持目的と期間を含む）

* [ ] 教職員の利用条件（受け付けるメールドメイン、学生との判定方法、取引成立時に開示する情報、出品時の確認書類、アカウントの有効期限）
