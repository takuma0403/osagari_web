# 利用規約

> 利用規約の正本です。画面（`/terms`）にはこの本文を載せます。決めた経緯は [ADR 0036](../decisions/0036-terms-and-privacy.md)。プライバシーポリシーは [privacy.md](privacy.md)。
> 本文中の「（未定）」は、決まるまで公開できない箇所です。

この規約は、佐賀大お下がりフリマ（以下「本サービス」）の利用条件を定めるものです。本サービスを利用する人（以下「利用者」）は、この規約に同意したうえで利用してください。

### 第１条（本サービスと運営者）

1. 本サービスは、佐賀大学の学生どうしがお下がり品を売り買いするための場を提供します。本サービスが行うのは、出品・一覧・検索と、代金のやり取りの記録です。
2. 本サービスは**佐賀大学の公式サービスではありません**。大学とは関係のない個人が運営しています（以下「運営者」）。
3. 運営者の氏名は本サービス上に掲げません。法令にもとづく求めがあった場合は、遅滞なくお答えします。
4. 利用者どうしの連絡（Microsoft Teams など）と商品の受け渡しは、当事者どうしで行います。本サービスにはチャット、商品への質問、配送、受け渡しの代行の機能はありません。

### 第２条（試験運用）

1. 現在、本サービスは**試験運用中**です。代金・手数料・売上・出金の表示と操作は試験用の記録で、実際のお金の支払い・受け取りは発生しません。
2. 試験運用中は、本サービスを実際の売買（お金のやり取りを伴う取引）に使わないでください。
3. 本サービスの決済を本番の形で始めるときは、この規約を改定し、事前にお知らせします（第11条）。

### 第３条（利用資格とアカウント）

1. 利用できるのは、佐賀大学から `学籍番号（8桁）@edu.cc.saga-u.ac.jp` のメールアドレスを与えられている学生だけです。
2. アカウントは1人1つとし、ほかの人に使わせたり、譲ったりしてはいけません。パスワードは利用者が責任をもって管理してください。
3. アカウントには、学籍番号から計算した有効期限（入学年度＋修業年限の年の3月31日）があります。有効期限を過ぎると、アカウントは失効します。
4. 退学したときは、本サービスから退学の申請をしてください。運営者が受け付けてアカウントを削除します。
5. 失効・削除のときは、利用者の商品を取り下げ、承認待ちの購入希望を期限切れにし、取引中の取引をキャンセルします。
6. 大学のメールが使えなくなると、ログイン時の再確認ができなくなり、ログインできなくなります。

### 第４条（出品）

1. 出品するには、学生証の画像を登録し、運営者の審査で承認を受ける必要があります。学生証の画像の扱いは [プライバシーポリシー](privacy.md) に定めます。
2. 出品者は、自分が所有し、売る権利をもつ物だけを出品できます。商品の説明と写真は、実物の状態どおりに書いてください。
3. 次の物は出品できません。\
   （1）試験の答案・過去問の配布物、レポートなどの代行物\
   （2）医薬品・医療機器・サプリメント\
   （3）酒類・たばこ\
   （4）危険物・武器\
   （5）偽造品・海賊版・違法コピー（コピーした教科書を含む）\
   （6）個人情報を含む物（名前入りの学生証など）\
   （7）チケット・金券・商品券\
   （8）生き物\
   （9）盗品・法令に違反する物
4. 運営者は、この規約に反する出品を、予告なく停止することがあります。

### 第５条（取引）

1. 売買の契約は、購入者と出品者のあいだで結ばれます。運営者は売買の当事者ではありません。
2. 購入者が購入希望を出し、出品者が1人を選んで承認した時点で取引が成立します。48時間以内に承認されなかった購入希望は期限切れになります。
3. 取引が成立すると、双方の学籍番号を相手に開示します。成立する前に、学籍番号を相手に開示することはありません。開示された学籍番号は、その取引の連絡と受け渡しのためだけに使ってください。
4. 受け渡しは、購入者が商品を確かめたうえで、出品者が表示するQRコードを読み取るか、出品者から届いた完了リンクを開くか、完了コードを入力して完了させます。受け渡しを完了できるのは購入者だけです。商品を受け取る前に完了させないでください。
5. 出品者は、取引の成立時に表示される確認に同意したあとは、受け渡しの場でQRコードを読み取ってもらうことを忘れないでください。**読み取りや完了の操作を忘れたことによる不利益について、運営者は責任を負いません。**
6. 本サービスは、一定の期間がたっても受け渡しを自動で完了にすることはしません。取引が進まなくなったときは、当事者どうしで話し合ってください。解決しない場合は窓口（第12条）に申し出てください。運営者が事情を確かめ、取引をキャンセルすることがあります。

### 第６条（キャンセルと返金）

1. 取引が成立したあとのキャンセルは、購入者と出品者の**双方が同意した場合だけ**できます。キャンセルすると購入者に返金し、商品は公開中に戻ります。
2. 前項の例外として、次の場合はどちらかの同意がなくてもキャンセルし、返金します。\
   （1）どちらかのアカウントが失効・削除されたとき\
   （2）トラブルへの対応のため、運営者がキャンセルするとき
3. **受け渡しが完了したあとは、キャンセルも返金もできません。**
4. キャンセルの回数を記録します。回数が多い利用者には、警告やアカウントの停止を行うことがあります。

### 第７条（代金・手数料・売上）

1. 試験運用中（第２条）は、この条のお金はすべて試験用の記録で、実際には動きません。
2. 購入者が支払う代金は、商品に表示された価格です。
3. 手数料は、価格に手数料率を掛けた額の1円未満を切り捨てた額です。出品者の売上は、価格から手数料を引いた額です。
4. 手数料率は、出品画面に表示します。取引に使う手数料率は取引が成立した時点の率で、そのあと率が変わっても、成立した取引の率は変わりません。
5. 出品者の売上は、受け渡しが完了した時点で確定します。確定した売上は、出金を申請して受け取ります。
6. アカウントが失効・削除されたときに出金していない売上は、失効・削除の日から**6か月以内**に窓口（第12条）に申し出れば出金します。6か月を過ぎると出金を求めることはできません。有効期限が近づいたら、早めに出金してください。

### 第８条（禁止行為）

利用者は次のことをしてはいけません。\
（1）法令や大学の規則に反すること、またはそのおそれのあること\
（2）第４条で禁じた物の出品、実物と異なる説明での出品\
（3）試験運用中に、本サービスを実際の売買に使うこと\
（4）取引で知った相手の学籍番号などの情報を、取引以外の目的で使ったり、ほかの人に伝えたりすること\
（5）ほかの人のアカウントを使うこと、アカウントを譲ったり貸したりすること\
（6）受け渡しを完了させる操作を相手に強いること、受け取る前に完了させること\
（7）本サービスの外での取引に誘い、手数料を免れようとすること\
（8）嫌がらせ、脅し、差別など、ほかの利用者を傷つけること\
（9）本サービスの動作を妨げること、不正にアクセスすること、通常の画面以外の手段で大量に操作すること\
（10）そのほか、運営者が不適切と判断すること

### 第９条（利用の停止）

1. 利用者がこの規約に反したとき、またはそのおそれがあると運営者が判断したときは、予告なく、出品の停止、取引のキャンセル、アカウントの停止・削除を行うことがあります。
2. 運営者は、これらの措置の理由を説明する義務を負いません。

### 第10条（免責）

1. 運営者は、商品の品質・状態・権利、利用者どうしのやり取り、受け渡しについて保証しません。利用者どうしのトラブルは当事者どうしで解決してください。運営者は原則として仲裁しません。
2. 運営者は、本サービスの内容を変えたり、一時的または永続的に止めたりすることがあります。
3. 運営者は、本サービスに関して利用者に生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。責任を負う場合も、その取引の代金の額を上限とします。ただし、消費者契約法などの法令でこの制限が認められない場合は、その法令に従います。

### 第11条（規約の変更）

1. 運営者は、この規約を変更することがあります。変更するときは、変更の内容と効力が生じる日を、効力が生じる日より前に本サービス上でお知らせします。
2. 効力が生じた日のあとも本サービスを使った利用者は、変更後の規約に同意したものとみなします。
