# プライバシーポリシー

> プライバシーポリシーの正本です。画面（`/privacy`）にはこの本文を載せます。決めた経緯は [ADR 0036](../decisions/0036-terms-and-privacy.md)。利用規約は [terms.md](terms.md)。
> 本文中の「（未定）」は、決まるまで公開できない箇所です。

佐賀大お下がりフリマ（以下「本サービス」）の運営者は、利用者の個人情報を次のとおり扱います。

### 第１条（運営者）

1. 本サービスは、佐賀大学とは関係のない個人が運営しています。
2. 運営者の氏名・住所は本サービス上に掲げません。個人情報保護法にもとづく求めがあった場合は、遅滞なくお答えします（第８条の窓口へ）。

### 第２条（取得する情報）

1. 運営者は、次の情報を取得します。

| 情報 | 取得するとき |
| --- | --- |
| 大学のメールアドレス、学籍番号（学生のみ。メールアドレスの@より前） | 新規登録 |
| 学生か教職員かの別 | 新規登録 |
| 入学年度、学部・学科（学生のみ）、アカウントの有効期限（学生は学籍番号から計算、教職員は認証コードを確認した日から計算） | 新規登録、教職員は認証コードの確認 |
| パスワード（復元できない形に変換して保存し、元のパスワードは保存しません） | 新規登録、パスワードの再設定 |
| 学生証の画像、教職員の身分証（職員証など）の画像（撮り直し・再提出の前の画像を含む） | 学生証・身分証の登録 |
| 出品した商品の情報と写真 | 出品・編集 |
| 購入希望・取引・キャンセル・受け渡し・売上・出金の記録 | 取引の各操作 |
| 退学・退職の申請をした日時 | 退学・退職の申請 |
| ログインの記録（セッション、ログイン時の再確認の日時、使った端末の識別子、パスワードの入力ミスの回数） | ログイン |
| 認証コードを送った記録 | 新規登録、ログイン時の再確認、パスワードの再設定 |
| 本サービスへのアクセスの記録（日時、操作の種類、エラー、接続元のIPアドレス、ブラウザの種類） | 本サービスの利用 |

2. 端末の識別子は、ブラウザの保存領域（localStorage）に作るランダムな値です。運営者は、そこから端末やあなたを特定できない形（ハッシュ値）でだけ保存します。
3. ログイン状態の保持のために、`__session` という名前のCookieを1つだけ使います。ほかのCookieや、アクセス解析・広告のためのツールは使いません。
4. アクセスの記録には、メールアドレス・学籍番号・パスワード・認証コードを書き込みません。

### 第３条（利用の目的）

運営者は、取得した情報を次の目的で利用します。\
（1）佐賀大学の学生・教職員であることの確認と、アカウントの登録・ログイン・本人確認のため\
（2）出品・一覧・検索・取引・代金の記録など、本サービスを提供するため\
（3）取引が成立したときに、取引の相手に学籍番号（教職員はメールアドレス）を開示するため（第５条）\
（4）学生証・身分証の画像による出品者の審査と、不正行為の抑止のため。利用者どうしのトラブルや不正が起きたときに、当事者を特定するため\
（5）規約に反する行為への対応（出品やアカウントの停止など）と、問い合わせへの対応のため\
（6）アカウントの有効期限の管理、失効・削除の処理、未出金の売上の精算のため\
（7）本サービスの不具合の調査と、安全に動かすため

### 第４条（学生証・身分証の画像）

1. 学生証・身分証の画像は、出品者の審査（学生は学生証の番号とログインに使ったメールアドレスの学籍番号が一致するか、教職員は身分証の氏名・所属とメールアドレスから本人と確かめられるか）と、不正行為の抑止・トラブル時の当事者の特定のためにだけ使います。
2. 画像は外から見られない保存場所に置き、利用者本人にも表示しません。見られるのは審査をする運営者だけで、見るたびに、見た人と日時を記録します。
3. 撮り直しや再提出で使われなくなった画像も含めて、アカウントの失効・削除から**3年間**保存し、その後に自動で削除します。

### 第５条（第三者への提供）

1. 取引が成立したとき（出品者が購入希望を承認したとき）に、購入者と出品者の学籍番号（教職員はメールアドレス）を**取引の相手に開示**します。本サービスを登録・利用することで、この開示に同意したものとします。成立する前に開示することはありません。
2. 前項のほか、次の場合を除いて、本人の同意なく個人情報を第三者に提供しません。\
   （1）法令にもとづく場合（裁判所・警察などからの法令にもとづく照会を含む）\
   （2）人の生命・身体・財産を守るために必要で、本人の同意を得ることが難しい場合\
   （3）そのほか個人情報保護法が認める場合

### 第６条（外部サービスの利用）

1. 本サービスは、次の外部サービスを使って動いています。個人情報は、これらのサービスの設備に保存・送信されます。運営者は、各サービスの利用条件とセキュリティの対策を確かめたうえで使います。

| サービス | 使い道 |
| --- | --- |
| Google Cloud（Cloud Run、Cloud Storage、Cloud Logging、Cloud Scheduler、Secret Manager） | プログラムの実行、学生証・身分証の画像、商品写真の保存、アクセスの記録 |
| Firebase Hosting（Google） | 画面の配信 |
| Turso | データベース（アカウント・商品・取引の記録） |
| Gmail（Google） | 認証コードのメールの送信 |

2. 保存する国：個人情報は、次の国の設備に保存します。

| 国 | 保存する情報 | その国の個人情報保護の制度 |
| --- | --- | --- |
| 日本（東京） | データベースの記録（アカウント・商品・取引など） | 個人情報保護法 |
| アメリカ合衆国 | 学生証・身分証の画像、商品写真 | [個人情報保護委員会が公表している情報](https://www.ppc.go.jp/personalinfo/legal/kaiseihogohou/)（「外国における個人情報の保護に関する制度等の調査」のアメリカ合衆国） |

3. 前項の外部サービスを提供する Google と Turso は、アメリカ合衆国の事業者です。メールの送信やアクセスの記録などは、アメリカ合衆国を含む国の設備で扱われることがあります。

### 第７条（保存する期間）

1. 運営者は、次の期間、情報を保存します。

| 情報 | 期間 |
| --- | --- |
| 学生証・身分証の画像 | アカウントの失効・削除から3年。過ぎたら削除します（見た人と日時の記録は残します） |
| メールアドレス、学籍番号、入学年度・学部、商品の情報と写真、取引・売上・出金の記録など、アカウントに結びつく情報 | アカウントの失効・削除から3年。過ぎたら削除するか、個人を特定できない形にします |
| 認証コード、ログイン時の再確認、受け渡しのトークンなど一時的な情報 | それぞれの有効期限が切れたあと、短い期間で削除します |
| アクセスの記録 | 30日（Cloud Logging の標準の保存期間）。過ぎたら自動で削除されます |

2. 法令で保存が求められる場合は、その期間保存します。

### 第８条（開示・訂正・利用停止などの求め）

1. 本人は、自分の個人情報について、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止、提供の記録の開示を求めることができます。
2. 求めるときは、窓口に連絡してください。本人であることを、大学のメールアドレスへの連絡などで確かめたうえで、法令に従って遅滞なく対応します。手数料はいただきません。
3. 窓口：（未定）問い合わせの窓口は決まりしだい書きます。運営者の氏名が相手に伝わらない形にします。

### 第９条（安全のための措置）

運営者は、個人情報を守るために次の措置をとります。\
（1）通信はすべて暗号化（HTTPS）します。\
（2）パスワード、認証コード、セッション、端末の識別子、受け渡しのトークンは、元に戻せない形（ハッシュ値）で保存します。\
（3）学生証・身分証の画像は、外から見られない保存場所に置き、運営者が見るたびに記録します。\
（4）個人情報を扱えるのは運営者だけにし、アクセスの記録にはメールアドレス・学籍番号などを書き込みません。\
（5）情報の漏えいなどが起きたときは、法令に従って個人情報保護委員会と本人に報告します。

### 第10条（このポリシーの変更）

このポリシーを変更するときは、変更の内容と効力が生じる日を、効力が生じる日より前に本サービス上でお知らせします。利用の目的を本人の同意が必要な形で変えるときは、あらためて同意をいただきます。
