# ADR 0022: 購入希望がなくなったときの商品ステータスと、フェーズ1の承認期限

- 日付: 2026-10-22
- 状態: 採用
- 関連する章ID: DEAL-1, JOBS-1, JOBS-2, DB

## 背景

購入希望・承認・却下の API（#25）を作るにあたり、[未決事項](../product/open-questions.md) の次の2点が決まっていなかった。

- 購入希望ありの商品で、購入希望がすべて却下・期限切れ・取り下げになったときに、商品ステータスを公開中へ戻すか。
- 購入希望の承認期限（48時間）が、決済サービスのオーソリ有効期限と合っているか。

## 決定

- 有効な購入希望（取引のステータスが `requested`）が0件になったら、商品を「購入希望あり」から「公開中」に戻す。却下（#25）でも期限切れ（JOBS-1, #31）でも同じ規則にする。戻すときは公開日時（新着順の並び）を変えない。
- 出品者が購入希望ありの商品を取り下げたときは、その商品の購入希望をすべて却下して枠を解放する（同じトランザクションで行う）。
- フェーズ1（決済はモック）の承認期限は要件どおり48時間にする。期限を過ぎた購入希望は、定期処理を待たずに承認できない（409）。オーソリ有効期限との照合は、決済サービスを選ぶときまで未決のまま残す。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 公開中に戻す（採用） | 商品の状態が実態（希望なし）と一致し、一覧・画面の表示と食い違わない | 却下・期限切れのたびに商品も更新する |
| 購入希望ありのまま | 更新が少ない | 希望がないのに「購入希望あり」と表示される |
| 48時間のまま（採用） | 要件どおり。モックではオーソリ期限の制約がない | 本番の決済サービスによっては見直しが要る |
