# ADR 0033: アカウント失効時の商品・取引の扱いと日次ジョブ

- 日付: 2026-10-28
- 状態: 採用
- 関連する章ID: AUTH-3, DEAL-1, DEAL-4, JOBS-1, CARD, STORAGE

## 背景

日次ジョブ（#35）でアカウントの失効と学生証画像の削除を作るにあたり、次のことが決まっていなかった。

- 未決事項「失効時に、進行中の取引、公開中の商品、未出金の売上をどう扱うか」（[product/open-questions.md](../product/open-questions.md)）。これまでは使えない出品者の商品を一覧・商品ページから読み取り時に除くだけで、ステータスは変えていなかった（[ADR 0018](0018-browse-visible-items.md)）。失効した人はログインできないため、取引中の取引は受け渡し完了も双方同意のキャンセル（DEAL-4）もできず、代金が預かられたまま止まる。
- 学生証の削除予定日（`student_cards.delete_after`）の起点となる「失効日」をいつにするか（[ADR 0014](0014-student-card-retention.md)）。
- 学生証のアップロードURLを発行したまま登録されなかったオブジェクトが、学生証バケットに残ること（#15 からの申し送り）。

## 決定

日次ジョブ（`POST /api/internal/jobs/daily`）で、有効期限を過ぎたアカウント（状態が有効または停止）を1人ずつ失効させ、同じトランザクションで次を行う。

| 対象 | 扱い |
| --- | --- |
| 本人の商品（下書き・公開中・購入希望あり） | 取り下げにする |
| 本人が出した、または本人の商品への承認待ちの購入希望 | 期限切れにして枠を解放する。承認待ちがなくなったほかの人の商品は公開中に戻す（[ADR 0022](0022-deal-request-item-status-and-approval-deadline.md)） |
| 本人が当事者の取引中の取引 | キャンセルにして購入者に返金する（DEAL-4 の双方同意の例外）。商品は、本人が出品者なら取り下げ、購入者なら公開中に戻す |
| 取引完了済みの取引・未出金の売上 | 変えない（売上の扱いは未決のまま残す） |
| 学生証（再提出で置き換えた行を含むすべて） | 削除予定日を「失効日 + 3年」にする |
| セッション | すべて無効にする |

- **失効日**は、有効期限（その日の終わりまで使える）の翌日とする。ジョブを動かした日ではなく有効期限から決めるので、ジョブが遅れても削除予定日は変わらない。
- 失効によるキャンセルは当事者の同意日時を入れない。キャンセル回数（DEAL-4）を数えるときは、同意日時のないキャンセルを利用者の回数に含めない（回数の集計はまだ実装していないため、集計を作る issue で守る）。
- 同じ日次ジョブで、削除予定日（日本時間の日付）を迎えた学生証画像を、予定日の当日から消し、`image_deleted_at` を記録する（行と閲覧記録は消さない）。画像がすでにない場合も削除済みとして記録する。
- 同じ日次ジョブで、作られてから24時間以上たち、`student_cards` に登録されていない学生証バケットのオブジェクトを消す（アップロードURLの有効期限は15分）。
- どの処理も何度行っても結果は同じにし、失敗したら 500 を返して Cloud Scheduler に再試行させる（JOBS-1）。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 商品の取り下げ＋取引のキャンセル（採用） | 失効した人が関わる取引が止まったまま残らない。相手の代金が返る | DEAL-4「双方の同意のみ」に例外ができる |
| 商品だけ取り下げる | DEAL-4 を変えない | 取引中の取引が完了もキャンセルもできずに残る |
| 何も変えず読み取り時に除くだけ（ADR 0018 のまま） | 実装が最小 | 取引と預かった代金が止まったまま残る |
| 購入希望を却下にする | 商品の取り下げと同じ扱い | 相手から見て、出品者が断ったように見える |
| 購入希望を期限切れにする（採用） | 相手の操作ではなく時間で終わったことが伝わる | — |
| 孤立画像を日次ジョブで消す（採用） | 登録済みの画像と区別して消せる | バケットの一覧の権限が要る |
| 孤立画像をバケットのライフサイクルで消す | アプリの処理が要らない | 登録済みの画像と区別できない（一時の置き場から移す設計変更が要る） |
