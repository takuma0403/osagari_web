# ADR 0003: 手数料率は取引成立時の値を適用する

- 日付: 2026-10-14
- 状態: 採用
- 関連する章ID: PAY-2, DEAL-1, ADMIN

## 背景

PAY-2 には「手数料率は管理画面から変更でき、取引ごとに適用した料率を記録する」とあるが、どの時点の料率を取引に適用するかは書かれていなかった。#6 で管理：設定（AdminSettings）のデザインを追加し、ユーザーのレビューで「保存後に成立する取引から新しい料率が使われます」という表示が了承された。

## 決定

- 取引に適用する手数料率は、取引が成立した時点（出品者が購入希望を承認した時点）の設定値とし、Transaction に記録する。
- 料率を変更しても、成立済みの取引の料率・手数料・売上は変わらない。
- 管理画面での入力は % で小数点以下2桁まで（0〜100%）。保存はベーシスポイントの整数（glossary の `feeRate`）。

料率の値そのもの（open-questions の「手数料率」）は引き続き未決。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 取引成立時の料率（採用） | 代金を預かる時点で手数料と売上が確定し、出品者に説明しやすい | 購入希望を出した時点の表示と差が出る可能性がある（料率の変更は頻繁でない前提） |
| 購入希望を出した時点の料率 | 購入者が見た条件と一致する | 手数料は出品者の売上に関わるもので購入者の支払額は変わらない。成立しない購入希望にも記録が要る |
| 受け渡し完了時の料率 | 売上確定の時点と一致する | 取引中に料率が変わると、成立時に出品者へ示した売上と変わってしまう |

## 影響

- 更新したドキュメント：docs/product/06-payment.md（PAY-2）
- 実装への影響：承認API（#25）で、承認の条件付きUPDATE と同じトランザクションで現在の料率を Transaction に記録する。管理：設定API・画面（#36, #37）は % ⇔ ベーシスポイントを変換する
