# ADR 0032: 売上管理画面の手数料率の表示と、出金申請の確認

- 日付: 2026-10-27
- 状態: 採用
- 関連する章ID: PAY-2, PAY-5, DS-4

## 背景

売上管理（[Sales](../design/screens/Sales.dc.html)）を実装するにあたり（#34）、デザインと仕様で次の食い違いと抜けがあった。

- 画面下の注記が「手数料率は仮の値（10%）で表示しています。」だが、暫定の料率は 5%（[ADR 0017](0017-fee-rounding-and-provisional-rate.md)）。また料率は管理画面で変えられるようにし（PAY-2、#36・#37）、取引ごとに成立時の料率で手数料を記録する（[ADR 0003](0003-fee-rate-applied-at-deal.md)）ため、1つの固定の料率では明細を説明できない。
- 「出金を申請する」を押したときの確認がデザインにない。出金は取り消せない（[ADR 0029](0029-sales-and-payout-mock.md)）。
- 明細の行を押したときの行き先がデザインにない。

## 決定

- 明細の行は「¥売値 − 手数料（料率） ¥手数料」の形（例 `¥1,550 − 手数料（5%） ¥77`）にし、取引成立時に記録した料率（`feeRateBasisPoints`）を出す。料率・手数料・売上はサーバーの値をそのまま出す（PAY-2）。
- 画面下の「手数料率は仮の値（…）で表示しています。」の注記は出さない（ユーザーの決定）。
- 「出金を申請する」は、`ConfirmDialog` で出金する額（出金できる売上）と取り消せないこと、モックで実際のお金は動かないことを示してから申請する。申請できたら `Toast` で「出金を申請しました」と知らせ、応答の出金後の売上で表示を置き換える。
- 出金できる売上が 0 円のときは「出金を申請する」を押せなくする。申請が 409 になったら（ほかの端末で出金済みなど）、エラーを出して売上を読み直す。
- 明細の行は商品詳細（`/items/:shareId`）へのリンクにする（ユーザーの決定）。取引中・取引完了の商品も、商品詳細は売り切れとして開ける（[ADR 0018](0018-browse-visible-items.md)）。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 行ごとに適用した料率を出し、注記は出さない（採用） | 料率を変えても、取引ごとの手数料の根拠が見える | デザインから行の表示が変わる |
| 注記を 5% に直して残す | デザインの見た目のまま | 管理画面で料率を変えると事実と合わなくなる |
| 注記を「成立した時点の料率で計算」に変える | 料率に左右されない | 行ごとの料率はわからない |
| 明細の行を商品詳細へのリンクにする（採用） | どの商品の売上かを確かめられる | デザインにない導線が増える |
| 明細の行を取引詳細へのリンクにする | 取引の経過を見られる | 売上の確認には商品の方がわかりやすい（ユーザーの判断） |
| ConfirmDialog で確認する（採用） | 取り消せない操作を誤って押さない。受け渡し完了の確認（DEAL-3）と同じ部品 | 1回多く押す |
| 確認なしで申請する | デザインどおり | 誤って押すと取り消せない |
