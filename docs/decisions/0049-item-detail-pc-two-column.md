# ADR 0049: 商品詳細の PC 幅レイアウト

- 日付: 2026-11-03
- 状態: 採用
- 関連する章ID: DS-1, FE

## 背景

[ADR 0048](0048-user-layout-pc-width.md) で、商品詳細（`/items/:shareId`）は PC 幅でも 560px の列のままにした。1280px で開くと左右が大きく空き、1080px に広げた一覧から開いたときに列の幅が急に変わる（#133）。

## 決定

- 商品詳細の列は、一覧・出品・取引の画面と同じ最大 1080px にする（`UserLayout wide`）。
- 1024px 以上では `TwoColumn` の `narrowStart` で2カラムにする。左が写真（360px の正方形・角丸。本文をスクロールしても上に残す）、右が見出し・価格・承認待ち・商品の情報・説明・出品者。
- 下部の「リンクをコピー」と主ボタンは、出品画面と同じく右カラムにそろえる。
- 読み込み中・見つからない・エラーの表示は、最大 560px の幅で中央に置く。
- 1023px 以下の見た目と DOM の順は変えない（スマホでは `TwoColumn` が枠を持たない）。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 写真 360px・右に情報（採用） | 出品画面（写真欄 360px）と並びがそろう。説明や商品の情報の行を広く取れる | 写真は大きく見せられない |
| 左右半分ずつ | 写真を大きく見せられる | 本文の幅が狭くなり、出品画面と並びが違う |
| 560px の列のまま（ADR 0048） | 変更がない | 1280px で左右が大きく空く |

## 影響

- 更新したドキュメント：[design/README.md](../design/README.md)（DS-1）、[ADR 0048](0048-user-layout-pc-width.md) の状態。
- 実装：`app/src/routes.tsx`（商品詳細を `UserLayout wide` に移す）、`features/items/pages/DetailPage`（`TwoColumn` と PC 幅の CSS）、`ItemGallery` の `className`（#133）。
