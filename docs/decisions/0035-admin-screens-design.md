# ADR 0035: 管理画面「ユーザー」「出品・取引」「設定」のデザイン

- 日付: 2026-10-29
- 状態: 採用
- 関連する章ID: ADMIN, DS

## 背景

未決事項「管理画面『ユーザー』『出品・取引』『設定』のデザイン（キャンバスには『学生証審査』だけがある）」が残っていた。
その後 #6 で [AdminUsers](../design/screens/AdminUsers.dc.html)・[AdminDeals](../design/screens/AdminDeals.dc.html)・[AdminSettings](../design/screens/AdminSettings.dc.html) を取り込んだが、
[ADR 0034](0034-admin-users-deals-settings.md) で決めた操作のうち、デザインに描かれていないもの（停止の解除など）がある。

## 決定

- 取り込み済みの AdminUsers・AdminDeals・AdminSettings を正本とする。
- デザインにない部分は、新しい見た目を作らず既存の部品で補う。
  - **停止の解除**：停止中のユーザーでは「アカウントを停止」の位置に「停止を解除」を出す。
  - **確認**：アカウントの停止・退学による削除・出品の停止・取引のキャンセル（返金）は `ConfirmDialog` で確認してから行う。
  - **一覧の続き**：ユーザー・出品・取引の一覧は、続きがあれば下に「もっと見る」ボタンを出す。
  - **読み込み中・0件・エラー**：学生証審査（AdminCard）と同じく「読み込み中…」と `InfoBox` で表す。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 今のデザインを正本にし、既存部品で補う（採用） | すぐ実装でき、見た目が他の画面とそろう | 補った部分はキャンバスにない |
| 先にキャンバスを描き足す | キャンバスとコードが一致する | 実装が待たされる |
| 確認なしで即実行 | 操作が速い | 取り消せない操作（削除・返金）を誤って押せる |
