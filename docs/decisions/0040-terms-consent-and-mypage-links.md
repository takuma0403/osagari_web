# ADR 0040: 新規登録時の規約への同意とマイページからの規約の導線

- 日付: 2026-11-01
- 状態: 採用
- 関連する章ID: AUTH-1, FE-1, SCREEN, DS-3

## 背景

利用規約・プライバシーポリシー（[ADR 0036](0036-terms-and-privacy.md)、画面は [ADR 0038](0038-legal-pages-build-time-markdown.md)）はログイン画面のリンクからしか開けず、新規登録時に同意も示していなかった。公開（M7）の前に、登録時の同意と、ログイン後にいつでも開ける導線を用意する（#109）。規約画面の戻るは商品一覧（`/`）固定で、未ログインの利用者は開いた元の画面にかかわらずログイン画面へ送られていた。Claude Design のキャンバスには同意文も導線もない。

## 決定

- 新規登録の最初の画面（`/signup`）の送信ボタンの下に「登録すると利用規約とプライバシーポリシーに同意したものとみなします。」と両文書へのリンクを置く。チェックボックスは置かず、同意したことは DB に記録しない。パスワード再設定（`/password-reset`）では出さない。
- マイページの設定の一覧（売上管理・学生証の登録）の下に「利用規約」「プライバシーポリシー」の行を足す。
- 規約画面の戻るは、アプリ内から開いたときは開いた元の画面へ（履歴を1つ戻る）。URL を直接開いて戻り先がないときは従来どおり商品一覧（未ログインならガードがログイン画面へ送る）。取引詳細などと同じ扱い。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 同意文だけ（採用） | 登録の手間が増えない。DB・API を変えずに済む | 個々の利用者の同意日時は残らない |
| 同意のチェックボックスを置く | 同意の意思がはっきりする | 登録の操作が増える。フェーズ1は試験運用で売買しない |
| 同意日時・規約の版を DB に記録する | 規約改定時に誰が古い版に同意したか分かる | API・マイグレーションが要る。現時点で改定の運用がない |
| 戻るは商品一覧に固定（従来） | 単純 | ログイン前の画面から開くとログイン画面へ飛ばされ、入力中の登録画面に戻れない |
