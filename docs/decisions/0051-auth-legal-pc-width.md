# ADR 0051: ログイン前の画面と規約の PC 幅レイアウト

- 日付: 2026-11-04
- 状態: 採用
- 関連する章ID: DS-1, FE

## 背景

[ADR 0048](0048-user-layout-pc-width.md) で、ログイン前の画面（ログイン・新規登録・パスワード再設定・再確認）と規約は PC 幅でも 560px の列のままにした。1280px で開くと左右が大きく空く。キャンバスには PC 版がないため、並べ方を決める必要があった（#135）。

## 決定

- ログインは 560px の列のまま、スマホと同じ並びにする（ADR 0048 のまま）。
- ログイン以外のログイン前の画面と規約の列は最大 1080px にする（`UserLayout wide`）。
  - 新規登録・認証コード・パスワード設定・再設定・再確認は、共通の枠 `AuthFormLayout` で、1024px 以上のときに地を `--color-bg` にする。ヘッダーから下は最大 440px の白いカードにして中央に置く。入力が1〜2項目なので2カラムにはしない。
- 規約は2カラムにせず、本文を 1080px の列いっぱいに流す。
- 560px の列は、ログインと「ページが見つかりません」などに残す。
- 1023px 以下の見た目と DOM の順は変えない（スマホではカードが枠を持たない）。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| ログイン：560px のまま（採用） | スマホのデザインどおりで、見慣れた形のまま | 1280px で左右が空く |
| ログイン：左に紹介・右に入力と新規登録 | 横の空きを使える | 試したが、並びがしっくりこなかった |
| ログイン：左に紹介と入力・右にボタン | 説明から入力まで左で読み進められる | 試したが、並びがしっくりこなかった。ボタンをフォームの外に置くため `form` 属性も要る |
| ログイン：中央のカード | 手順の画面と見た目がそろう | 紹介とフォームが縦に長く並び、横が空く |
| 手順の画面：中央のカード（採用） | 共通の枠だけを直せば全画面に効く。入力欄が広がりすぎない | 地の色が手順の画面だけ変わる |
| 手順の画面：左に見出し・右に入力 | 横の空きを使える | 項目が少ないので左右とも余白が多い |
| 規約：1080px（採用） | ほかの画面と列の幅がそろい、列の幅を増やさずに済む | 1行が長くなる |
| 規約：720px | 1行がおよそ40字に収まる | 列の幅が1つ増える。狭く感じる（試したが採らなかった） |
| 規約：1080px で目次と本文 | 章を行き来しやすい | 見出しから目次を作る処理が要る |
| 規約：560px のまま | 変更がない | 1280px で左右が大きく空く |
