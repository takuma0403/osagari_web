# ADR 0050: 学生証・売上管理の PC 幅レイアウト

- 日付: 2026-11-04
- 状態: 採用
- 関連する章ID: DS-1, FE

## 背景

[ADR 0048](0048-user-layout-pc-width.md) で、学生証（`/mypage/student-card`）と売上管理（`/mypage/sales`）は PC 幅でも 560px の列のままにした。1280px で開くと左右が大きく空き、1080px のマイページから開いたときに列の幅が急に変わる（#134）。商品詳細は [ADR 0049](0049-item-detail-pc-two-column.md) で先に 1080px・2カラムにした。

## 決定

- 両画面の列を最大 1080px にする（`UserLayout wide`）。1024px 以上では `TwoColumn` で2カラムにする。
- 売上管理は `narrowStart`。左（360px）に売上の概要と出金のボタンを置き、明細をスクロールしても上に残す。右に「売上の明細」の見出しと明細を置く。
- 学生証は `even`（左右半分ずつ）。左に説明・審査の段階・却下のお知らせ（読み込み中・エラーもここ）と、画像を選ぶボタン（承認済みなら「出品する」）を置く。右に登録した画像・保管の注意書きを置く。
- 学生証のボタンはスマホでは画像の下にある。PC 幅で左カラムに出すときは、CSS で見た目だけ動かすと Tab の順が食い違うので、`matchMedia`（`lib/useMediaQuery.ts`）で幅を見て DOM 上の位置を変える（ADR 0048 の上部ナビと同じ考え方）。
- 1023px 以下の見た目と DOM の順は変えない（スマホでは `TwoColumn` が枠を持たない）。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 売上管理：左に概要・右に明細（採用） | 明細が多くても出金できる金額とボタンが見えたまま | 明細の幅が狭くなる |
| 売上管理：左右半分ずつ | 概要を大きく見せられる | 概要の枠が横に間延びする |
| 売上管理：1カラムで明細を2列 | 明細を一覧しやすい | 時系列の明細が2列に分かれて読みにくい |
| 学生証：左に審査とボタン・右に画像（採用） | 状態の説明と次にする操作が左にまとまり、画像を大きく見せられる | ボタンの位置を JS で切り替える必要がある |
| 学生証：ボタンも右（画像の下） | DOM の順を変えずに済む | 審査の段階から操作までの視線の移動が大きい |
| 学生証：560px のまま | 変更がない | 1280px で左右が大きく空く |

## 影響

- 更新したドキュメント：[design/README.md](../design/README.md)（DS-1）、[ADR 0048](0048-user-layout-pc-width.md) の状態と本文の注記。
- 実装：`app/src/routes.tsx`（両画面を `UserLayout wide` に移す）、`features/sales/pages/SalesPage`、`features/student-card/pages/StudentCardPage`（`TwoColumn` と PC 幅の CSS）、`layouts/UserLayout` のコメント（#134）。商品詳細（ADR 0049）の左カラムを伸ばす指定も、CSS の読み込み順に頼らないよう詳細度を上げた。
