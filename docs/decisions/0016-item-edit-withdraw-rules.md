# ADR 0016: 商品を編集・取り下げできるステータスと下書きのチェック

- 日付: 2026-10-20
- 状態: 採用
- 関連する章ID: ITEM, DEAL-1, DEAL-4

## 背景

[product/open-questions.md](../product/open-questions.md) の OPEN-DERIVED「商品の『取り下げ』が取引中にもできるか」が未決だった。[ITEM](../product/03-listing.md) は「いつでも取り下げにできる」とし、[DEAL-4](../product/05-deal-flow.md) は取引成立後のキャンセルを双方の同意に限っていて、両立の仕方が決まっていなかった。

あわせて、ITEM は「取引中は価格などを編集できない」とだけ書いていて、購入希望ありの商品を編集できるか、下書きでどこまで入力を求めるかが決まっていなかった。出品API（#19）の着手時に決めた。

## 決定

| 操作 | できるステータス |
| --- | --- |
| 編集 | 下書き・公開中・取り下げ |
| 取り下げ | 下書き・公開中・購入希望あり |
| 公開・再出品 | 下書き・取り下げ |

- 取引中の商品は取り下げも編集もできない。やめるときは DEAL-4 の双方同意のキャンセルで公開中に戻してから操作する。
- 購入希望ありの商品は、どの項目も編集できない。
- 下書きの保存で必須なのはタイトルだけにし、公開するときにすべての共通項目（写真1枚以上を含む）を確かめる。
- ステータスの変更と編集は、現在のステータスがこの表のとおりのときだけ更新する条件付きUPDATEで行う（[DB](../tech/database.md)）。

## 理由と検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| 取引中は取り下げ不可（採用） | DEAL-4（双方同意のみ）と矛盾しない。購入者が一方的に取引を失わない | 出品者がすぐにはやめられない |
| 取引中も取り下げ可（一方的なキャンセル扱い） | 出品者の自由度が高い | DEAL-4 の決まりを変えることになる |
| 取引中は説明文と写真だけ編集可 | 細かい訂正ができる | 合意した後に商品の説明が変わる |
| 購入希望ありは編集不可（採用） | 枠を確保したときの内容・価格と食い違わない | 誤字も直せない |
| 購入希望ありは価格以外を編集可 | 細かい訂正ができる | 希望を出した後に内容が変わる |
| 下書きはタイトルだけ必須（採用） | 途中で保存できる | DB の列の多くが NULL を許す |
| 下書きも全項目必須 | スキーマが単純 | 下書きの意味が薄い |
